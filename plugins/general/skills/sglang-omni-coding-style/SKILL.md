# SGLang Omni coding style

Read the [coding style](references/coding-style.md) before changing or reviewing code. Check the relevant sections for naming, type annotations, imports, error handling, and tests.

Follow the target repository's instructions. Apply SGLang Omni's package boundaries, tooling commands, and test paths only in SGLang Omni. In another repository, use its own layout and validation commands.
